# 書体とロゴ（#47）

## 書体

候補 4 組（今・A アーケード・B サイバー・C スポーツ中継）を、実際の画面の部品で並べた見本（`font-specimen.png`、元は `tools/brand/font-specimen.html`）をレビューし、組ではなく役割ごとに選んだ。

| 役割 | 書体 | 理由 |
|---|---|---|
| ワードマーク・32px 以上の告知（STOPPED・LEVEL UP・大当たり） | Dela Gothic One | 極太でパチンコ台のロゴのような押し出し。小さいと潰れるので大きい場所だけ |
| 見出し・ボタン（16〜28px） | RocknRoll One | 弾む形で、小さくても字の形が保たれる |
| 数字（確定ミリ秒・カウントダウン・HUD・残高） | Unbounded（700 / 900） | 幅広の極太で、得点表示の勢いが一番出た |
| 計器のラベル（SCORE・COMBO・h2） | Chakra Petch 600（大文字・字間広め） | 角ばってゲームの計器らしい |
| 本文・小さいラベル | M PLUS 1p（400 / 500 / 700） | 癖がなく小さくても読める |
| 等幅（slot・JSON・アドレス） | Share Tech Mono | 本物の等幅。ゼロに斜線 |

外したもの: Orbitron（「7」が鉤の形で一瞬で読めない）、Rajdhani（細く高揚感が弱い）、JetBrains Mono・Space Grotesk・Noto Sans JP（地味に見える原因）。

ライセンス: すべて Google Fonts の SIL Open Font License 1.1。CSS から Google Fonts を読み込む（`app/src/index.css` の先頭）。

## ロゴ

- マーク: `app/public/logo-mark.svg`（favicon も同じ）。金庫の 12 片の判断リングを稲妻が貫く。図形だけで、書体に頼らない
- 画面のロゴは `app/src/components/Logo.tsx`（インラインの SVG）で動かす（`logo-motion.png` は 0.2 秒ごとの 24 コマ）
  - リングが回り続け、その上を 1 片ぶんの光が逆向きに周回する
  - 稲妻が 2.4 秒ごとに光って跳ねる
  - ワードマークは光が流れ続け、4 秒ごとに色ずれのグリッチが走る
  - 確定の瞬間はマークが叩かれて跳ね、ワードマークが白く飛ぶ
  - reduced-motion ではグローバルの規則で止まる
- OGP 画像: `app/public/og.png`（1200×630）。作り直しは `node tools/brand/og.mjs`

画面の確認: `app-1280x900.png`・`app-390x844.png`（はみ出し・折り返しの崩れなし）。

## 箱で区切らない画面と演出の層（#56）

- セクション（背景・枠・角丸のカード）を使わない。中央に舞台（`.arena`）、左右に浮かぶ計器（`.gauge`・名札は `.gauge-tag`）を置き、画面全体を 1 枚の HUD にする。構成と面の扱いの正本は `app/src/cockpit.css`
- 奥の層（`OverdriveBack`）：回転光・光漏れ・六角格子・光の柱・巨大な文字の円環・Sokketsu マークの透かし・文字の帯・データの雨・16 進ダンプ・slot のブロックの帯・確定の閃光
- 手前の層（`OverdriveFront`）：周辺減光・走査線・グリッチの帯・四隅の HUD 枠・目盛り・計器の読み・REC とタイムコード
- 舞台（`VaultHalo`・`StageDeck`）：レーダー・六角形・弧・衛星・文字の環・目盛り（外と内）・判断の 3 択の軌道・照準・矢印・四方の読み・衝撃波・光の柱・床・巨大な「即決」・4 工程のランプ。段階が変わるたびに内から外へ順に展開する
- 背景の層は止めた絵として濃く重ね、動きは舞台・データの雨・ティッカーなど狭い面積に集める。画面全体が少しずつ動く層は、headless の録画でコマが落ちる割に動画の尺では動いて見えないため
- Solana の公式ロゴ（`app/public/brand/solana-logo.svg`）は配布元（solana.com/branding）の SVG と SHA-256 で一致するものをそのまま使い、ヘッダーの専用の枠（内側は無地の余白）に 1 か所だけ置く。導入の展開もこの枠にはかけない。変形・影・縁取り・色変え・ほかの図像との重ね合わせはしない。Solana Foundation と提携していない旨を併記する
- 既定の表示言語は英語。右上のボタンで日本語に切り替えられ、選んだ言語を覚える
- ワードマークは大文字（SOKKETSU）で見せる。HUD のラベルや Solana のワードマークとそろえるため。文字列は Sokketsu のまま（読み上げで 1 文字ずつ読まれないように）。文章の中では Sokketsu と書く
- 広い画面（1100px 以上・高さ 700px 以上）はスクロールなしで全部を見せる（ファーストビュー）
- エスクローの 4 工程の帯（`EscrowSteps`）：いまの工程が開き、何が起きているかを 1 文で出す
- HUD の部品（`app/src/hudkit.css`）：ボタン・レベル・スコア・コンボ・Alpenglow の計器を、角を切り落とした同じ作りにそろえる
- prompt-motion.com から取り入れた手法：判断のリール（spearwtf-3c1fd1）・照準が締まる（reflex-cloud-72ffe5）・点の格子のマーク（kyonax-on-tech-aabc1d ほか。工程ごとに 25% 灯る）・計器が中央から開く導入（dale-vaz-cc612a）
- 背景の巨大ロゴ・文字の円環・軌道は、ダイヤルのように段階的に回す（コマの合間は止まるので録画の負荷が小さい）

画面の確認: `cockpit-1280x900.png`（判断中）・`cockpit-390x844.png`（確定）。

待機中の動きの量（`tools/motion`・10 秒）：

| 条件 | 本番（改修前） | 改修後（ローカル） |
|---|---|---|
| 1280×900 静止 / 平均 | 5% / 10.24% | 31% / 13.94% |
| 390×844 静止 / 平均 | 0% / 10.23% | 0% / 18.14% |
| reduced-motion 静止 | — | 85% |

1280×900 の静止の増加は、GPU の無い headless の録画で同じコマが並ぶことによる（GPU のあるブラウザでは 60fps）。
